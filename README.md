## Описание

Учебный интернет-магазин книг Харуки Мураками, разработанный на Bootstrap.

## Используемый фреймворк

Bootstrap 5.3.8.

## Способ подключения

Bootstrap подключён через CDN. Файл `css/custom.css` подключён после Bootstrap.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог книг;
- `product.html` — страница книги;
- `order.html` — форма заявки;
- `css/custom.css` — дополнительные стили;
- `images/` — обложки книг;
- `README.md` — описание проекта.

## Реализованные компоненты

- `navbar`, `breadcrumb`;
- `card`, `btn`, `badge`, `alert`;
- `modal`;
- `form-control`, `form-select`, `input-group`, `form-check`;
- `accordion`, `carousel`, `nav-tabs`;
- `table-responsive`.

## Самостоятельные доработки

- тематика книг Харуки Мураками, 5 карточек в каталоге;
- карусель на главной странице;
- вкладки «Описание» и «Характеристики» на странице книги;
- подвал на всех страницах, активный пункт меню на каждой странице;
- в форме заявки выбор книги обязателен, у всех полей есть `name`;
- в `custom.css` добавлены стили карточек и видимый фокус.

## Как проверить

1. Открыть `index.html` и пройтись по навигации.
2. В каталоге проверить карточки, кнопка «Заказать» открывает модальное окно.
3. Открыть страницу книги, переключить вкладки и вопросы.
4. Проверить форму заявки.
5. Проверить адаптивность через DevTools.
